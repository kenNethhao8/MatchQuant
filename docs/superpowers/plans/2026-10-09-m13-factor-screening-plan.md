## 1. 当前判断与进入条件

M13A 已实现离线因子快照和查询，可输出近期积分、进失球、对手赛前 Elo、主客场收缩均值和日历休息天数。M13A 报告记录了 282 项离线测试通过；真实样本查询为 20 场，其中 18 场 ready、2 场因 `Ipswich` 未识别而 needs_review。报告状态仍为 `READY_FOR_REVIEW`，独立验收尚未完成；查询也明确标注历史快照覆盖未核实。

因此可以开始规划筛选，暂不把 M13A 因子当作有效 Alpha，也不直接进入权重搜索。筛选实现的先决条件是：

1. 对 M13A 完成独立验收。若发现时间边界、批次冻结、载荷或来源绑定问题，先在 M13A 范围修复并复核。
2. 执行前只读核对代码提交、数据版本、cutoff、行数和输入哈希；不得把文档中上一次记录的值直接当作当前值。
3. 在首个面板或报告生成前冻结 `evaluation_contract`，包括候选清单、因子定义、时间切分、统计方法和筛选阈值。

## 2. 阶段定位与范围

建议把该工作定位为 **M13C-FS：历史因子面板与筛选**。M13B 的增量更新、parent lineage 和重建/增量等价服务于持续维护快照；本次筛选可从冻结的完整历史按时间顺序重建，不依赖线上式增量维护，故建议暂缓 M13B，待需要滚动更新因子状态时再启动。此为阶段顺序建议，不删除或改写既有 M13B 设计。

本阶段完成后只产出完整筛选报告和冻结候选名单。因子不会进入 M1–M12 概率计算、结算 schema、发行包或站点运行流程。筛选中的关联结果不能解释为因果关系，也不能单独证明因子提升了预测效果。

## 3. 冻结候选范围

只筛选 M13A 已定义且可复算的历史赛果因子，不临时增加因子：

| 候选组 | 候选项 | 备注 |
|---|---|---|
| 近期积分 | `points_rate_5`、`points_rate_10` | 胜 3 分、平 1 分、负 0 分，按队伍视角计算 |
| 近期进失球 | `goals_for_mean_5/10`、`goals_against_mean_5/10` | 主客两侧分别保留，窗口不完整时保留实际样本数 |
| 对手强度 | `opponent_pre_elo_mean_5/10` | 使用每场当时批前的对手 Elo，不以最终 rating 回填 |
| 主客场表现 | `venue_goals_for_shrunk`、`venue_goals_against_shrunk` | 保留先验来源、样本数和收缩标志 |
| 休息间隔 | `rest_calendar_days` | 仅表示日历日差，不解释为精确小时或完整赛程覆盖 |
| 现有 Elo 对照 | `elo_rating` | 与 Elo baseline 高度重叠，先作为冗余/基线对照项，不自动列入新增 Alpha 候选 |
| 派生差值 | 两侧均有效时的主客差值 | 在 contract 中列全公式；任一侧缺失时差值为缺失，不补零 |

窗口 5 与 10、积分与进球、对手 Elo 与球队 Elo 都可能高度相关，筛选报告必须按候选组呈现，不能只报告最后留下的变量。

## 4. 历史面板构建

需要增加一个离线、可复现的研究流程，例如 `result-factor-panel` 和 `result-factor-screen`。实现应复用 M13A 的计算函数、时间线和校验逻辑，不复制另一套因子公式，也不逐场重复构建完整快照。

面板每场比赛一行，至少记录：`match_id`、日期、赛季、as-of 边界、M13A 因子版本、各因子值、各因子的 `n` / missing / small-sample 状态，以及来源数据版本和哈希。赛果标签单独加入筛选分析层，不能参与该行赛前因子计算。

强制时间规则：

- 严格按日期/时间批次推进；一批所有比赛先读取同一份批前状态，再统一更新赛果。
- 因子生成只读取当场之前可用的结果；同批或未来比分的变更不能改变该批及之前的因子。
- `match_id` 重复、非法日期、输入版本或 manifest 不匹配时明确阻断，不猜测合并。
- 未知队、冷启动、小样本、缺失因子继续保留在总样本清单中并标记原因。不得为获得好看的样本而删除失败比赛。
- 真实历史和生成面板只读；结果文件写到唯一研究输出目录，不写入正式 data root、current pointer、Git 或发布包。

## 5. 评估合同与筛选方法

### 时间切分

沿用既有研究评估约定：2015-16 至 2021-22 用于因子状态初始化和发现分析；2022-23、2023-24 作为早期时间验证块，用于检查筛选信号是否跨赛季重复。两段数据都属于回溯研究；经过本阶段筛选后，它们不能再被称为未见测试集。

既有评估已查看 2024-25 结果；2025-26 是否完全未参与候选选择和人工改参尚未确认。因此两季不参与本轮筛选门槛或 shortlist 排名。只有完成暴露审计后，才能决定是否把 2025-26 用作一次性回溯评估；无法确认时也按已暴露历史处理。未来独立效果验证应另行锁定前瞻预测及配置，再等待赛果。

当前历史数据版本、行数和 cutoff 在执行时重新核验。M13A 报告曾记录 4180 行、cutoff 2026-05-24；这只是该次输入证据，不证明当前数据完整或最新。

### 不依赖拟合权重的筛选指标

本阶段不拟合 logistic 系数、不学习模型参数，也不搜索概率混合系数。先做：

1. **可用性**：每个因子的覆盖率、缺失率、有效样本数、小样本率，按赛季和主客侧拆分。
2. **变化与冗余**：检查常数/近常数列；在发现期计算因子间 Spearman 相关，`|rho| >= 0.90` 作为同组候选的冗余提示。报告原值，不以相关阈值自动删列。
3. **与赛果的单变量关联**：对三分类赛果报告预先固定分箱下的 mutual information，以及主胜/平/客胜 one-vs-rest 效应量。连续因子的分箱边界只在发现期确定，再原样用于时间验证块；不按验证结果改分箱。
4. **稳定性与不确定性**：分别报告两个验证赛季结果；使用自然周分块的 bootstrap，固定 seed、1000 次重采样和 95% 区间。对预先指定的互信息统计量使用按赛季分层的自然周块置换生成探索性 p 值，再按候选家族做 Benjamini-Hochberg 校正；置换细节须在 contract 中冻结。`q < 0.10` 只作探索性筛查参考，不代表预测效果证明。
5. **基线重叠**：报告因子与冻结 baseline 概率/状态的相关性。Elo rating 或与 baseline 等价的变量优先标记为“解释/对照”，不因单变量关联强就宣称带来增量价值。

阈值和分箱在执行前写入并冻结 contract。建议的初始 coverage 门槛为总体有效率至少 80%、每个验证赛季至少 70%；低于门槛的变量可以保留为解释字段，但不进入 shortlist。若 review 认为门槛不合适，应在读取筛选结果前修订并留版本记录。

### Shortlist 分类

每个候选最终归入以下一种状态，并给出证据和理由。建议 `advance_to_weighting_review` 至少满足：时间语义通过、总体及逐赛季 coverage 达标、因子有非零变化、互信息关联在冻结的验证块通过预注册筛查门槛，并且至少一个预注册类别的 one-vs-rest 效应在两个验证赛季方向一致、合并后的分块区间未跨零；若证据不足则保留为 `display_only`。具体阈值必须在看验证结果前写入 contract。

- `advance_to_weighting_review`：时间语义通过、coverage 达标、存在非零变化、关联信号在验证赛季可重复，且没有明显的基线重复问题。
- `display_only`：定义清楚且可解释，但覆盖不足、信号不稳定或证据区间过宽。
- `redundant`：与同组因子高度重叠；记录代表项选择依据及被保留的备选。
- `reject`：时间泄漏、计算来源或语义错误、近常数，或无法可靠复现。

`advance_to_weighting_review` 只表示值得进入下一阶段的候选，不表示因子有效、应当赋权或已改善预测。

## 6. 后续赋权边界

权重属于单独的 M15 计划和验收阶段。只有 shortlist 冻结后，才拟定少量、透明、可回退的候选模型；训练/选择只能使用预注册的时间训练与验证数据，final test 只评一次。权重阶段须比较固定 baseline、单因子候选和组合候选，主指标为 pooled multiclass Log Loss，Brier 为辅助指标，Accuracy 仅作补充；按赛季、类别、coverage 和校准诊断报告结果。

任何候选都必须与 baseline 在完全相同的 fixture/date batches 上比较。测试结果不达门槛、样本不足或缺信息时，默认保留原 baseline；无合法因子输入时概率须与 baseline 一致。回溯表现不证明未来表现、盈利或投注价值，只有另行锁定的前瞻结果能提供新的未见证据。
